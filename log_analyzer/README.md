# Log Analyzer

A command-line example that scans a log file for failed login events and summarizes the counts by username.

## Requirements

- Python 3
- No third-party packages

## Run

Place a log file named `application.log` in the working directory, then run:

```powershell
python log_analyzer.py
```

The sample log is intentionally not included. Use a sanitized or synthetic log file; real logs can contain personal or security-sensitive data.
