# URL Detector

A command-line example that inspects URLs for basic structural properties and heuristic indicators such as IP addresses, encoded characters, and suspicious keywords.

## Requirements

- Python 3
- No third-party packages

## Run

```powershell
python url_detector.py
```

This is a heuristic demonstration, not a security scanner. Its results should not be used as the sole basis for deciding whether a URL is safe.
